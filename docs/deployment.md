# Deployment
Development uses SQLite and optional demo. Production requires PostgreSQL, TLS termination, strong Django/token secrets, explicit hosts, Redis cache, `DEBUG=False`, secure cookies/HSTS, collected static files, and `ENABLE_DEMO_UI=False`. Production configuration fails when demo/default keys are present or admin MFA is disabled. Enrol every admin in tested django-otp TOTP and verify operational login policy before launch. Run `collectstatic` and migrations once per release. Keep static general support independently served. Use encrypted database backups, restore drills, immutable image tags, database-compatible rollback migrations, and prior-image rollback.
